# 台股智勝寶典 (Taiwan Stock Pro)

專為台灣股票新手設計的 **0 到 100 實戰交易、看盤教室、公司深度研究、熱潮辨識與股票能不能買四維評估系統**。界面現代美觀，採用專業金融深色風格 (Dark Fintech Theme)，完全依據台股在地市場規則（紅漲綠跌、T+2交割、盤中零股、三大法人籌碼、二代健保稅務）與經過實戰驗證的金融理論（巴菲特價值投資、彼得林區 PEG、怪老子指數化複利、財報三表庫存去化、柴鼠兄弟高股息拆解）開發。

## 🌟 六大核心系統模組架構

### 1. 🧭 新手 0 到 100 實戰通關手冊
- **關卡 01：開戶與交割常識**（證券集保戶 vs 交割銀行戶、T+2 避雷互動日曆模擬器、整張 1000 股與盤中零股、限價單 vs 市價單防坑）。
- **關卡 02：手續費與稅金精算**（0.1425% 券商手續費、電子下單折扣 2.8~6折、證券交易稅 0.3% / 0.1% / 0.15%、二代健保補充保費 2.11%、損益平衡檔數）。
- **關卡 03：三大面向核心剖析**（基本面、技術面、台股獨有籌碼面三大法人與融資融券）。
- **關卡 04：熱門 ETF 與配息真相**（0050 市值型 vs 00878 高股息、填息 vs 貼息真相、收益平準金機制）。
- **關卡 05：新手防割韭菜保命五大天條**（嚴禁融資借款、7%-10% 停損紀律、2% 風險資金控管、防 LINE 炒股詐騙）。

### 2. 📊 看盤實戰圖解教室
- **互動 K 線走勢圖 (Interactive Candlestick Chart)**：
  - 符合台股在地慣例：**紅漲 🔴、綠跌 🟢**。
  - 均線切換：5MA (週線)、20MA (月線/多空分水嶺)、60MA (季線/生命線)。
  - 成交量指標 (Volume) 與即時滑鼠懸停數值與教學解讀小貼士。
  - 多檔代表性台股場景切換：台積電 (2330) 多頭突破、聯發科 (2454) 箱型整理、投機地雷股 (9999) 避雷針。
- **五檔報價 (Order Book) 與內外盤實戰模擬器**：
  - 買一至買五、賣一至賣五排隊視覺化。
  - 內外盤即時比例條 (外盤買方追價推升 vs 內盤賣方砍單下殺)。
  - 互動模擬按鈕：買盤敲外盤、賣盤砍內盤、主力假大單誘多抽單陷阱解密。
- **K 線型態圖解百科**：大紅K、長黑K、十字星、鎚子線、避雷針、早晨之星等圖解卡片。

### 3. 🔍 深度公司研究與最新熱潮雷達 (新增開源大模組)
- **新手第一次買股票完全流程**：從挑券商、申請憑證、下單 App 介面、盤中零股指定限價 ROD、到成交回報與 T+2 交割。
- **手把手公司體質研究 7 步法 (SOP)**：
  1. 商業模式（賺誰的錢、內外銷、客戶集中度）
  2. 月營收年增率 (YoY / MoM，每月 10 號前必看)
  3. 獲利三率（毛利率、營業利益率、淨利率，本業 vs 業外）
  4. 存貨天數與資產負債（庫存去化、負債比）
  5. 現金流量表（營業現金流與自由現金流 FCF，防黑字倒閉）
  6. 籌碼動向與董監持股質押率（內部人持股真話）
  7. 估值與安全邊際（本益比河流圖位階）
- **當前台股最新風口熱潮地圖**：
  - AI 伺服器與高效能運算 (HPC)
  - CoWoS / SoIC 先進封裝與設備
  - 高階水冷散熱與熱管理系統
  - 矽光子與共同封裝光學 (CPO)
  - 重電設備與綠能儲能電網
- **「真熱潮」vs「假熱潮/蹭題材」六大照妖鏡檢驗系統**：
  1. 營收純度檢驗（佔比是否 > 15%~20%）
  2. 毛利率是否同步跳升
  3. 客戶名單是一級巨頭還是二三線送樣
  4. 資本支出 (CAPEX) 是否擴張
  5. 三大法人真槍實彈買超
  6. 大股東與內部人有無高檔出脫轉讓
- **全公開・開源與官方權威資料庫完全導航**：公開資訊觀測站 (MOPS)、證券交易所 (TWSE)、櫃買中心 (TPEx)、經濟部產業價值鏈平台、Goodinfo!、財報狗。

### 4. 🎯 「這檔股票能不能買？」四維體檢雷達 (核心評估系統)
- **四維 100 分制量化體檢模型**：
  1. 基本面與財報安全度 (40分)
  2. 估值面與安全邊際 (20分)
  3. 籌碼面與法人動向 (20分)
  4. 技術面位階與動能 (20分)
- **智能綜合評級 (S / A / B / C / D)**：
  - 綠/黃/紅三色決策燈號判定。
  - 具體進場策略、嚴格停損防守價格點位、風險警示。
- **雙模式運作**：支援真實經典台股案例快速驗證，亦支援**「自訂股票體檢模式」**。

### 5. 🧠 大師智慧與 YouTube 財經精華圖書館
- 萬字長影片提煉：巴菲特護城河、彼得林區生活選股與六大股票分類、綠角怪老子 0050/006208 被動複利聖經、財報狗股乾爹半導體庫存週期、柴鼠兄弟股添樂高股息除權息與融資斷頭潮、老王季線生命線與 2% 風控法則。
- **新手實戰段位自測大考驗 (5 題 Interactive Quiz)**。

### 6. 🧮 全功能實戰算力工具箱
- **台股交易手續費 & 損益平衡試算機**（含券商折扣、當沖降稅、保本回本股價門檻）。
- **三大合理股價估值試算器**（本益比法、殖利率還原法、彼得林區 PEG 成長估價法）。
- **定期定額複利滾雪球模型**（本金 vs 複利利息增長視覺化）。

## 🚀 快速啟動指南

```bash
# 1. 進入目錄
cd c:\Users\user\Desktop\teachstock

# 2. 啟動本機開發伺服器
npm run dev

# 3. 建置正式環境版本
npm run build

# 4. 預覽正式版本
npm run preview
```

瀏覽器訪問：`http://localhost:5173/` 或 `http://localhost:4173/`。
