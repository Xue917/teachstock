# 台股智勝寶典 (Taiwan Stock Pro) - 全平台雙端開源旗艦版

專為台灣股票投資人打造的 **0 到 100 實戰交易、看盤教室、全台產業版圖圖鑑、深度公司研究、熱潮偵測、高階技術面兵法、當沖絕技、散戶心態避坑與百萬致富藍圖全功能系統**。

支持 **手機端 (Mobile Phone) 與 電腦端 (Desktop)** 雙端完美自適應體驗，搭載手機專屬底部拇指操作導航欄 (Mobile Bottom Nav) 與全功能模組抽屜。

## 🌟 八大核心系統模組架構

### 1. 🧭 新手 0 到 100 實戰通關手冊
- **開戶與交割常識**（證券集保戶 vs 交割銀行戶、T+2 避雷互動日曆模擬器、整張 1000 股與盤中零股、限價單 vs 市價單防坑）。
- **手續費與稅金精算**（0.1425% 券商手續費、電子下單折扣 2.8~6折、證券交易稅 0.3% / 0.1% / 0.15%、二代健保補充保費 2.11%、損益平衡檔數）。
- **三大面向核心剖析**（基本面、技術面、籌碼面三大法人與融資融券）。
- **熱門 ETF 與配息真相**（0050 市值型 vs 00878 高股息、填息 vs 貼息真相、收益平準金機制）。
- **新手防割韭菜保命五大天條**（嚴禁融資借款、7%-10% 停損紀律、2% 風險資金控管、防 LINE 炒股詐騙）。

### 2. 📊 看盤實戰圖解教室
- **互動 K 線走勢圖 (Interactive Candlestick Chart)**：
  - 符合台股在地慣例：**紅漲 🔴、綠跌 🟢**。
  - 均線切換：5MA (週線)、20MA (月線/多空分水嶺)、60MA (季線/生命線)。
  - 成交量指標 (Volume) 與即時滑鼠懸停數值與教學解讀小貼士。
  - 多檔代表性台股場景切換：台積電 (2330) 多頭突破、聯發科 (2454) 箱型整理、投機地雷股 (9999) 避雷針。
- **五檔報價 (Order Book) 與內外盤實戰模擬器**：
  - 買一至買五、賣一至賣五排隊視覺化。
  - 內外盤即時比例條 (外盤買方追價推升 vs 內盤賣方砍單下殺)。
  - 互動模擬按鈕：買盤敲外盤、賣盤砍內盤、主力假大單誘多抽單陷阱解密。
- **K 線型態圖解百科**：大紅K、長黑K、十字星、鎚子線、避雷針、早晨之星等圖解卡片。

### 4. 🔍 深度公司研究與最新熱潮雷達

## 🚀 快速啟動指南

```bash
# 1. 進入目錄
cd c:\Users\user\Desktop\teachstock

# 2. 啟動本機開發伺服器
npm run dev

# 3. 建置正式環境版本
npm run build

# 4. 預覽正式版本
npm run preview
```

瀏覽器訪問：`http://localhost:5173/` 或 `http://localhost:4173/`。
雙擊專案目錄下的 **`push.bat`** 即可一鍵推送到您的 GitHub (`https://github.com/Xue917/teachstock.git`)！
