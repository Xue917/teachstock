# 台股智勝寶典 (Taiwan Stock Pro) - 百萬高手開源實戰旗艦版

專為台灣股票投資人打造的 **0 到 100 實戰交易、看盤教室、深度公司研究、熱潮偵測、高階技術面兵法、當沖絕技與百萬致富藍圖全功能系統**。

---

## 🌟 七大核心系統模組架構

### 1. 🧭 新手 0 到 100 實戰通關手冊
- **開戶與交割常識**（證券集保戶 vs 交割銀行戶、T+2 避雷互動日曆模擬器、整張 1000 股與盤中零股、限價單 vs 市價單防坑）。
- **手續費與稅金精算**（0.1425% 券商手續費、電子下單折扣 2.8~6折、證券交易稅 0.3% / 0.1% / 0.15%、二代健保補充保費 2.11%、損益平衡檔數）。
- **三大面向核心剖析**（基本面、技術面、籌碼面三大法人與融資融券）。
- **熱門 ETF 與配息真相**（0050 市值型 vs 00878 高股息、填息 vs 貼息真相、收益平準金機制）。
- **新手防割韭菜保命五大天條**（嚴禁融資借款、7%-10% 停損紀律、2% 風險資金控管、防 LINE 炒股詐騙）。

### 2. 📊 看盤實戰圖解教室
- **互動 K 線走勢圖 (Interactive Candlestick Chart)**：
  - 符合台股在地慣例：**紅漲 🔴、綠跌 🟢**。
  - 均線切換：5MA (週線)、20MA (月線/多空分水嶺)、60MA (季線/生命線)。
  - 成交量指標 (Volume) 與即時滑鼠懸停數值與教學解讀小貼士。
  - 多檔代表性台股場景切換：台積電 (2330) 多頭突破、聯發科 (2454) 箱型整理、投機地雷股 (9999) 避雷針。
- **五檔報價 (Order Book) 與內外盤實戰模擬器**：
  - 買一至買五、賣一至賣五排隊視覺化。
  - 內外盤即時比例條 (外盤買方追價推升 vs 內盤賣方砍單下殺)。
  - 互動模擬按鈕：買盤敲外盤、賣盤砍內盤、主力假大單誘多抽單陷阱解密。
- **K 線型態圖解百科**：大紅K、長黑K、十字星、鎚子線、避雷針、早晨之星等圖解卡片。

### 3. 🔍 深度公司研究與最新熱潮雷達
- **新手第一次買股票完全流程**：從挑券商、申請憑證、下單 App 介面、盤中零股指定限價 ROD、到成交回報與 T+2 交割。
- **手把手公司體質研究 7 步法 (SOP)**：
  1. 商業模式（賺誰的錢、內外銷、客戶集中度）
  2. 月營收年增率 (YoY / MoM，每月 10 號前必看)
  3. 獲利三率（毛利率、營業利益率、淨利率，本業 vs 業外）
  4. 存貨天數與資產負債（庫存去化、負債比）
  5. 現金流量表（營業現金流與自由現金流 FCF，防黑字倒閉）
  6. 籌碼動向與董監持股質押率（內部人持股真話）
  7. 估值與安全邊際（本益比河流圖位階）
- **當前台股最新風口熱潮地圖**：AI 伺服器、CoWoS 先進封裝、高階水冷散熱、矽光子 CPO、重電儲能電網。
- **「真熱潮」vs「假熱潮/蹭題材」六大照妖鏡檢驗系統**。
- **全公開・開源與官方權威資料庫完全導航**：公開資訊觀測站 (MOPS)、證券交易所 (TWSE)、櫃買中心 (TPEx)、經濟部產業價值鏈平台、Goodinfo!、財報狗。

### 4. ⚡ 高階技術兵法・當沖絕技與百萬資產藍圖 (🔥 全新升級高階系統)
- **當沖職業操盤手四大實戰絕技**：
  1. *開盤三法*：09:00-09:15 前三根 5 分鐘 K 棒定全天多空主調。
  2. *分時均價線 (VWAP) 攻防與回踩切入法*：市場全體成本線，站穩偏多，跌破偏空。
  3. *破解隔日沖大戶 (凱基台北、富邦建國、美林)*：掌握開高倒貨慣性與反手空點。
  4. *尾盤強鎖漲停板防守與防打開倒貨戰術*。
- **當沖五大保命鐵律**：13:00 前必須全數平倉、單筆 1.5% 停損、嚴防先賣後買借券地雷（一天最高罰 7%）、只做成交量前 50 大、單日虧損達 2% 立即關機。
- **高階技術指標底層物理學**：
  - *均線扣抵值 (Moving Average Draping)*：提前 5~10 天預判均線轉折支撐力道。
  - *格蘭碧八大法則 (Granville's 8 Rules)*：4 個買點與 4 個賣點終極母法。
  - *MACD 頂底背離戰法*：能量竭盡與極限抄底逃頂信號。
  - *布林通道擠壓噴發 (BBands Squeeze)*：極致收縮後喇叭開口的爆量主升浪。
  - *破解 KD > 80 高檔鈍化迷思*：超級妖股飆漲的起漲點標配。
- **台股實戰專有名詞大百科**：內建即時搜尋與分類過濾（逐筆交易、ROD/IOC/FOK、開盤試撮、注意處置股票關狗籠、全額交割、三大法人、隔日沖券商、融資維持率 130% 斷頭追繳、券資比軋空、董監質押、缺口理論、分時均價線 VWAP 等）。
- **新手到 100 萬「階梯式致富藍圖」**：
  - 階段一 (0 ➔ 10 萬)：本金地基與生存累積（70% 指數 ETF + 30% 現金，嚴禁當沖）。
  - 階段二 (10 ➔ 40 萬)：波段順勢突破與獲利槓桿（掌握投信認養飆股，嚴守 7% 停損）。
  - 階段三 (40 ➔ 100 萬+)：高期望值系統與複利收割（波段擴大利潤 + 小部位高勝率當沖加速器）。
- **操盤手數學期望值與風控試算器**：震撼教育新手——只要維持盈虧比 3:1，哪怕勝率只有 45%，大數法則將保證資產突破百萬！

### 5. 🎯 「這檔股票能不能買？」四維體檢雷達 (核心評估系統)

## 🚀 快速啟動指南

```bash
# 1. 進入目錄
cd c:\Users\user\Desktop\teachstock

# 2. 啟動本機開發伺服器
npm run dev

# 3. 建置正式環境版本
npm run build

# 4. 預覽正式版本
npm run preview
```

瀏覽器訪問：`http://localhost:5173/` 或 `http://localhost:4173/`。
雙擊專案目錄下的 **`push.bat`** 即可一鍵推送到您的 GitHub (`https://github.com/Xue917/teachstock.git`)！
